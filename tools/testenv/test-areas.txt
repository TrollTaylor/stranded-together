# Test areas: which hidden-test scenarios a change needs (tools/testenv/Select-Scenarios.ps1; docs/hidden-testing.md "Test economy").
#
# Two kinds of lines (a '#' starts a comment line):
#
#   area <name> [implicit | implicit-host | no-run] : <what it is>
#       Declares an area. Every scenario names the areas it checks in its "# covers:" header line.
#       implicit       every hidden run exercises it (the mod boots, the saves are redirected and compared, the online gate
#                      and the supervisor run in every run): any selected scenario covers it.
#       implicit-host  every two-game run (role host) exercises it (the link, the pose frames).
#       no-run         a change here needs no hidden game run (ctest, docs, research tooling, the launcher window).
#
#   <path glob> [~<regex>] <area> [<area> ...]
#       A changed file (repo-relative, forward slashes, PowerShell -like: '*' also crosses '/') touches these areas.
#       Without ~regex: the FIRST matching line gives the file's areas, so specific globs come before general ones.
#       With ~regex (case-insensitive, no spaces: use \s): EVERY matching line adds its areas when a changed line (added or
#       removed) of that file matches. These narrow the big files: real_body.cpp's private-room code needs a private-room run,
#       its other code does not. Changed lines over 200 characters (usage lists, log formats naming every feature) are not
#       matched.
#   A file no plain line matches is "unmapped": Select-Scenarios.ps1 warns, and its -Check (ctest st_testenv_select_tests)
#   fails for a tracked file. Add new source files here.

# ---- areas
area none no-run           : docs, unit tests (ctest), build files, research and release tooling
area research no-run       : census / catalog / audio probe tooling: only the probes that use it (select: probe)
area launcher-ui no-run    : the launcher window (no hidden run drives it; launcher_core_tests and the user's look)
area boot implicit         : the mod loads, hooks, overlay up, title, Continue, into the world (smoke)
area saves implicit        : the save redirect, foreign-save bypass, saves compared by hash (every run)
area testenv implicit      : the supervisor, the automation channel, Start-TestRun.ps1 (every run)
area link implicit-host    : the link v2 session, transports, pose frames between two games
area overlay               : the F9 menu, ImGui overlay, input, mouse lock, debug actions
area gate                  : the online gate: nothing the mod creates goes online (drops checked in the log)
area launcher              : the launcher's core: session.ini it writes (Local test), install, textures extraction start
area host-save             : the host-held save session: save transfer, guest title / waiting screen, reloads
area save-guard            : the save guard: saves never capture a carried Sam or a mod-built thing wrongly
area partner-holo          : the partner as the welcome hologram (partner_body=holo, the fallback)
area partner-body          : the partner's real body: spawn, pose, animation, character choice (host's screen)
area self-view             : the guest's own Fragile in place of Sam (self view, fit, follow mode)
area smooth                : smooth animation above 60 fps, pose interpolation and prediction
area skeleton              : Sam's exoskeletons on Fragile (exo carrier skeletons)
area hood                  : Fragile's rain hood on the exo carrier (STC1 v5 hood bytes, the unfold, her hair and hat under it)
area outfit                : the partner Sam's outfit, his head and hair
area face                  : Fragile's face: Sam's facial clips on her self view and on the partner body (face_sync, STJ1 face block)
area suit-colour           : Fragile's porter suit in Sam's suit colours (palette)
area textures              : Fragile's textures from the user's folder, hot reload, on her self view
area texture-share         : her textures over the link (STT1: pictures, ready-made recipes) on the other screen
area suit-defaults         : the ready-made gold / silver / colour folders, the automatic extraction
area gear                  : gear on the bodies: backpack, cargo, accessories, headgear, the BB pod
area gear-wear             : gear that wears out (the rain cover)
area boots                 : Fragile's boots (own / prop look)
area held-items            : what a player holds, in their hand on the other screen
area weapons               : weapons in hand
area menu-figure           : the cargo menu's Sam figure under the self view
area private-room          : the private room: entering, loading, the close-up, the black-screen fix
area collision             : player collision, no Climb on the partner
area name-tags             : name tags, the game's menu font
area voice                 : partner voice and the self-voice mute
area sound                 : partner sounds (footsteps, efforts) and their volume
area vehicles              : vehicle copies (vehicle_sync: look, state, sounds of the partner's vehicle)
area vehicle-share         : shared real vehicles: identity, summon, remote driving, handoff, persistence
area vehicle-hit           : vehicle hits, bumps and tackles
area ride                  : riding together: boarding, seats, ride camera, forced exits
area world-sync            : shared structures: builds, contributions, ladders, ropes, ziplines
area enemies               : enemy sync (docs/enemy-sync.md): P0 the read-only enemy census; later the mirrors, hits, bullets
area story                 : story tools, story loads
area dev-tools             : dev tools: spawn, goto, weather, refill, god mode
area quickstart            : the hidden runs' quickstart (start line)
