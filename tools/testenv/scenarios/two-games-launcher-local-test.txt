# The launcher's Local test, exactly as the button writes it (v0.19; docs/hidden-testing.md "launcherini"), hidden:
#   pwsh -File tools\testenv\Start-TestRun.ps1 -Scenario two-games-launcher-local-test -SeedSaves complete-100
# Start-TestRun.ps1 sees the 'launcherini' line, has StrandedTogether.exe --write-session local-test write host.ini and
# guest.ini (core::MakeLocalTestInis, the Debug options read from the game folder's launcher settings) into the run
# folder, and the supervisor runs both games on those files with only sandbox_saves / sandbox_foreign_saves swapped for
# the run's automation redirect (session-host-deployed.ini / session-guest-deployed.ini in the run folder). No "ini" line
# may change them. The guest's scratch is profile-only, as the launcher's local-guest folder.
# v0.18.0's Local test wrote no host_save: the waiting screen, the save transfer, the shared vehicles, riding together and
# vehicle hits never ran in the user's play test (the vehicles were the old see-through copies). Pass: all of them ON in
# both games from the launcher's own file; the guest's waiting screen (W1); the save transfer; the roadster in the start
# garage bound in both worlds and driven by the host with the guest's follower attached (G1); a summon (the host's truck,
# the guest's trike) mirrored in the other world within seconds, without anyone getting on (S1 / S2); the guest rides
# as the host's passenger (R1); no "co-op features OFF" notice and no FAULT.
