# Riding together, the forced exits with the HOST as the passenger (design M3.4; docs/real-partner-body.md section 24;
# the host plays its real save in real use, so its carried Sam must come back whole every time), hidden:
#   pwsh -File tools\testenv\Start-TestRun.ps1 -Scenario two-games-ride-forced-host -SeedSaves complete-100 -GuestSeed profile-only
# The guest drives the truck (CLAIM / GRANT), the host rides; each time the host's game puts its own Sam off by itself:
#   1. the link: the host's game drops every datagram for 2.5 s (coop_session 1) -> off after 1 s silent ("link lost"),
#   2. a crash: the guest's game stops its moving truck dead (ride_test 6) -> "crash", the game's hit on the host's Sam
#      (D3-3: "[vhit] ... hit Sam (#1) ... thrown off in a crash", knocked down, not killed),
#   3. the game takes the host's Sam (ride_test 7) -> off without a placement, capsule back on,
#   4. the driver (the guest) gets off while the host rides -> "the driver got off".
# Pass: every exit with the capsule counter back to 0 and the input back ("[overlay] riding: ... back"), the host on the
# ground beside the truck (the later boards work), no fault on either game. Check enlarged: E1 / E2a / E2b / E3 / E4
# (the host standing, or knocked down and getting up, beside the truck; never inside it, under the ground or floating).
