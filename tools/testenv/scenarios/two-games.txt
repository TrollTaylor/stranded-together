# Two games on one PC, hidden (Start-TestRun.ps1 -Scenario two-games -SeedSaves complete-100):
# the local two-player test of docs/sandbox-and-local-test.md on the private desktop. The first
# game is the host (role=host, UDP 27555 -> 27556), the second the guest (role=guest, its own mod
# folder automation\guest via ST_INSTANCE_DIR, second_instance=1: ds.exe's single-instance mutex
# is renamed for it). Both load their own scratch copy of the same save; each shows the other as
# the partner hologram, driven by the other game's poses over the loopback link. The supervisor
# samples RAM / CPU / GPU memory of both games (resources.csv, summary.json "resources").
# covers: link
role host
graphics low
timeout 360
waitready 90
@guest waitready 120
waitlog 120 \[overlay\] input attached
@guest waitlog 120 \[overlay\] input attached
# the title menu (~20 s after the first frame), CONTINUE selected
wait 25000
?screenshot 01-host-title
?@guest screenshot 01-guest-title
pad A 150
@guest pad A 150
wait 4000
until 240 5000 \[sync\] local player entity 0+ -> 0*[1-9A-F] => pad A 120
@guest until 240 5000 \[sync\] local player entity 0+ -> 0*[1-9A-F] => pad A 120
waitplayer 60
@guest waitplayer 60
# the link: both ends report the handshake, then each spawns the other's body
waitlog 60 \[link\] CONNECTED
@guest waitlog 60 \[link\] CONNECTED
# the 100% save loads the world 5-20 s after the player appears: 1 s pushes until the host's Sam walks
until 120 500 ly=32760 -> ok: .*player moved ([1-9]|[1-9][0-9]+)\.[0-9]+ m => pad none 1000 ly=32760
waitlog 60 \[sync\] partner body: hologram
# the second game logs in to the game server with the same Steam account as the first: the server refuses
# ("Unable to log in to Death Stranding game server. Launching in Offline Mode... Error Code: 50000", run
# 20261116-155336) and the game waits behind that notice until OK: A every 3 s until the partner spawns
@guest until 150 3000 \[sync\] partner body: hologram => pad A 120
screenshot 02-host-control
@guest screenshot 02-guest-sees-host
snapshot
@guest snapshot
# the host walks away 6 s: on the guest's screen the host's hologram walks off
pad none 6000 ly=32767
waitlog 5 pad none 6000 ly=32767 -> ok: .*player moved ([3-9]|[1-9][0-9]+)\.[0-9]+ m
@guest screenshot 03-guest-sees-host-walk
snapshot
@guest snapshot
# the host looks back: the guest's hologram stands where the guest's Sam is
pad none 1300 rx=32767
screenshot 04-host-looks-back
wait 2000
screenshot 05-host-sees-guest
@guest screenshot 05-guest-view
action log_status
@guest action log_status
menu open
wait 700
screenshot 06-host-debug-menu
menu close
@guest menu open
wait 700
@guest screenshot 06-guest-debug-menu
@guest menu close
wait 300
@guest quit
wait 3000
quit
