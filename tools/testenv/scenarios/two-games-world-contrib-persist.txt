# keeps the result, hidden, on the launcher's own Local test files:
#   pwsh -File tools\testenv\Start-TestRun.ps1 -Scenario two-games-world-contrib-persist -SeedSaves complete-100 -GuestSeed profile-only
# The host builds a postbox (level 1); both games pay all that level 2 still needs in the same step (@both): one shared
# total (the host's own 200 + the guest's 200 through AddOthers: the surplus counts toward level 3), exactly one level-up
# in each world (the host drops a second request while one waits or runs), level 2 in both. Then the host's game saves
# (its own autosave, into the run's scratch copy) and loads that save in the world; the guest follows (the host-held save).
# After the load: the postbox exists once in each world (offline 1), level 2, invested 0/0/400 in both, the guest's join
# binds it (created 0); a contribution after the load still goes through (the new world's epoch).
# Pass: the log lines below, no FAULT, no byte check failure, no OTGC WRITE, both games exit 0.
