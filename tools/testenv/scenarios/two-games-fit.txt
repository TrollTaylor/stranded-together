# Fragile (porter suit) with a fitted self view in two games, hidden (docs/real-partner-body.md section 16):
# the guest plays fragile_suit (the launcher's default guest character) with the self view and its fit;
# the host sees her body wearing the guest's mirrored gear. With the fit on the guest's sender measures
# each item against her proportions, so the host places it on her joints with the same fit (no wire
# change). Each host view twice: the guest's fit on, then off (`self_view 5 0`: measured on Sam's
# proportions, as before).
#   pwsh -File tools\testenv\Start-TestRun.ps1 -Scenario two-games-fit -SeedSaves complete-100

@guest until 240 5000 \[sync\] local player entity 0+ -> 0*[1-9A-F] => pad A 120

@guest waitplayer 60
waitlog 60 \[link\] CONNECTED
@guest waitlog 60 \[link\] CONNECTED

@guest until 150 3000 \[sync\] partner body: real 'sam' => pad A 120
