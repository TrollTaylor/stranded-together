# Shared real vehicles, ownership handoff (design M2.10 #4, M2.7; docs/real-partner-body.md section 23.13), hidden:
#   pwsh -File tools\testenv\Start-TestRun.ps1 -Scenario two-games-veh-handoff -SeedSaves complete-100 -GuestSeed profile-only
# 1. The host drives the truck a few metres and gets off (RELEASE); the guest's follower lets go. 2. The guest, placed
# beside it, gets on with X: CLAIM, the host GRANTs it, the guest drives away and the host's world follows; the guest gets
# off, the truck comes to rest and goes back to the host (RELEASE at rest, GRANT handback). 3. The lock: the host drives
# again; the guest, beside it, presses X: its game does not board (the follower holds the seat). 4. Both press X together
# at a parked truck: the host wins (DENY or GRANT host), the guest's Sam is put off (RideOffVehicleForcibly) if it got on.
# Pass: one driver at a time (never both "[vdrive] ... our Sam drives" for one id at once past the race), no fault.
