# The host drives the truck, the guest rides; forced saves on the guest's game (its sandbox scratch):
# A. two saves in a row: a save while carried (held, the ride ends, released, written) and more asked for at once while it
#    is held or written (the game or the guard refuses them; one that is taken runs at once on foot); then

#    save taken is written once);

#    a boarding request is on its way (the carry is refused while it is pending, or the game / the guard handles it).
