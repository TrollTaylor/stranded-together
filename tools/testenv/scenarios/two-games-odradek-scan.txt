# the launcher's own Local test files (host Sam, guest Fragile), odradek_scan_sync=1 on both (odradek_probe=1 too: the scans
# are driven with odra 2, the native trigger's writes on the machine's own thread, and the test pulses with odra 8):
#   pwsh -File tools\testenv\Run-Batch.ps1 -Scenarios two-games-odradek-scan -SeedSaves complete-100 -GuestSeed profile-only -Id round28-o3
# Each game announces the capability in a SOD1 HELLO (caps 0x01) on combat channel 6; a game's own pulse (its 3 -> 4 edge)
# goes out as a SOD1 SCAN {seq, origin, dir}; the other game restarts its own wave there inside its scan-machine detour (the
# machine idle: mode=full; showing marks: mode=visual), or queues the latest one while its own scan runs.
# Steps: the host scans, the guest shows it (10-*/11-*: the grid sweeping out from the host's position, 20 m west of her);
# the guest scans, the host shows it (20-*/21-*); both scan at once (each queued "busy_local_scan", each shown when its own
# wave ends); two test pulses from the guest while the host scans (the older "dropped: superseded"); a pulse 600 m away
# ("dropped: too_far").
# Pass: every step ok; the screenshots 10-guest-* / 11-guest-* show the host's scan on the guest's screen (the grid / ring
# centred on the host, not on Fragile, and no Odradek animation on her), 20-host-* / 21-host-* the guest's scan on the host's
# screen; no FAULT, no refused SOD1 message, no "not sent"; summary.json result pass.
