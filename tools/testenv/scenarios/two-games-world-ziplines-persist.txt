# Shared structures W4 (docs/world-sync.md): ziplines in the host's save, hidden, on the launcher's own Local test files:
#   pwsh -File tools\testenv\Run-Batch.ps1 -Scenarios two-games-world-ziplines-persist -Id round5-w4 -SeedSaves complete-100 -GuestSeed profile-only
# The host builds a zipline, the guest one (held, GBUILD, created by the host, mirrored back); both finish building. A save
# of the host's game is written (save_guard 1 4: the game's own autosave, into the run's scratch copy) and loaded in the
# world (save_guard 3; the guest follows: she loads the host's new save and joins again). Pass: after the load each world has
# each zipline exactly once (no duplicate, nothing lost), offline 1, the same ids, level 1, the same links in both worlds;
# the guest's second join binds them (created 0: they came from the host's save); no FAULT, no OTGC WRITE, both exit 0.
# covers: world-sync save-guard
role host
graphics low
timeout 360
launcherini local-test
start control 200
waitlog 10 \[world\] world sync ON \(host\): shared structures \(PCC structures, ladders and climbing ropes, ziplines
@guest waitlog 120 \[world\] guest: snapshot #1 complete: bound [0-9]+, created 0, removed 0, replaced 0
@both goto mknot-road
wait 4000

waitnew 5 \[world\] dev build: id [0-9]+ type 22 \(zipline\) anim 1 .* offline 1
@guest waitlog 10 \[world\] guest: mirror hid [0-9]+ -> gid [0-9]+ \(exact\) type 22 \(zipline\) anim 1 printer 1 \(the host's build\)
@guest pad none 1400 lx=32767
@guest pad none 450 ly=32767
@guest wait 1500
@guest action dev_build 22 1 16
@guest waitlog 10 \[world\] guest: local build type 22 \(zipline\) held, request #1 sent
waitlog 10 \[world\] host: the guest's build #1: created hid [0-9]+ type 22 \(zipline\) offline 1
@guest waitlog 10 \[world\] guest: build #1 confirmed as hid [0-9]+
wait 22000
